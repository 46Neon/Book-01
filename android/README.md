# Android app

Módulo previsto de Book-01 para Kotlin + Jetpack Compose, Room y WorkManager. La app tendrá una experiencia tipo hoja de cálculo: pestañas de libro, cuadrícula adaptable, filtros, totales y detalle de fila.

Este directorio todavía es documentación, no una APK ni código funcional. Próximo paso de implementación: crear el proyecto Gradle, navegación, tema/componentes de tabla y pruebas iniciales.
