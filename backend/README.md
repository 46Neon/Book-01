# Backend contable

Módulo previsto para API HTTPS, reglas del dominio contable, persistencia PostgreSQL y contrato OpenAPI. La APK y el futuro chatbot accederán únicamente mediante operaciones autorizadas de esta API.

El chatbot/MCP no se implementa aquí en Parte 1. El framework del servidor y el despliegue quedan pendientes de confirmar antes de escribir código productivo.
